### English Version

# 💬 my-chat-deepseek-r1-free

Welcome to **my-chat-deepseek-r1-free**, a simple yet powerful chat application that combines the elegance of HTML with the intelligence of AI! 🚀

---

## 🌟 Features

- **AI-Powered Conversations**: Leverages the capabilities of [DeepSeek](https://deepseek.ai) and [OpenRouter](https://openrouter.ai) to create dynamic and intelligent chat responses.
- **Volatile Data Storage**: Implements a lightweight, in-memory storage system for maintaining a simple conversation history.
- **User-Friendly Interface**: Built with clean and minimalistic HTML for a seamless user experience.

---

## 🛠️ How It Works

1. **Frontend**: A simple HTML-based chat interface for user interaction.
2. **AI Logic**: Uses AI to process user inputs and generate meaningful responses.
3. **Conversation History**: Maintains a temporary chat history using props, ensuring smooth and contextual conversations.
4. **API Key**: The `index.js` file contains the line:
    ```javascript
    const API_KEY = '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';
    ```
    This key will expire and needs to be replaced with a new token from [OpenRouter](https://openrouter.ai).

---

## 🚀 Getting Started

1. Clone the repository:
    ```bash
    git clone https://github.com/your-username/my-chat-deepseek-r1-free.git
    ```
2. Navigate to the project directory:
    ```bash
    cd my-chat-deepseek-r1-free
    ```
3. Open the `index.html` file in your browser to start chatting!
